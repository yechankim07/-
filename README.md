# Python GradeBook Project

한경국립대학교 공학설계입문 수업 실습 프로젝트입니다.
파이썬의 모듈화, 패키지 구조화, CSV 입출력 및 `unittest`를 활용한 성적 관리 프로그램입니다.

## 📁 프로젝트 구조

- **`gradebook.py`**: 단일 파일 구조 실행 실습[cite: 15]
- **`project_root/`**: 역할별 모듈 분리 실습[cite: 15]
- **`project_root_pkg/`**: 패키지 및 서브패키지 구조 확장 실습[cite: 15]
